# Voice2Do 产品需求文档

## 产品背景

用户有随时随地出现的各种各样的需求。通过最简单、没有门槛、快速的语音录入，用户可以将一闪而过的灵感、未来想做的事情和想法进行补充和记录。

## 产品架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   输入层    │     │   处理层    │     │   输出层    │
│  iOS 捷径   │────▶│  后端服务   │────▶│  Web 页面   │
│  语音录制   │     │ Gemini转写  │     │  时间轴     │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 输入层
- iOS 捷径快速拉起录音
- 以 POST 方式发送音频到后端

### 处理层
- 存储原始语音（可选）
- Gemini API 转写语音为文字
- 去除语气词（额、嗯、那个等）
- 存储到 Supabase

### 输出层
- Web 页面展示所有备忘
- 时间轴布局：近1月按天、1月-1年按月、超1年按年
- 风格：简约、温暖、有格调

## 用户场景

### 场景1：记录灵感
> 用户："我想去古天文台"
>
> 系统：保存为 "我想去古天文台"，分类为 memo

### 场景2：电影愿望（v0.2）
> 用户："那个，我想看那个沙丘2"
>
> 系统：保存为 "我想看沙丘2"，分类为 movie，提取电影名"沙丘2"
